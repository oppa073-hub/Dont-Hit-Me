# Don't Hit Me

운전석 1인칭 시점의 PC 아케이드 **택시 게임**입니다. 둥글게 휜 뉴욕풍 도시 도로를 달리며 손님을 태우고, 무단횡단자를 조향으로 피합니다.
혼자 한 달 안에 소규모로 완성하는 것을 목표로 만들었고, Unity 6 (URP)으로 개발했습니다.

## 게임 방식
- 차는 제자리에 있고 월드가 다가옵니다. 도로는 앞쪽으로 갈수록 아래로 휩니다 (`y = -curvature * z²`, 동물의 숲 같은 원통형 맵).
- **택시**: 인도에서 기다리는 손님(느낌표)에게 차를 붙여 세우면 옆 시점 대화 후 탑승하고, 목적지 근처에서 정차하면 요금을 정산합니다.
- **무단횡단자**: 부딪히면 목숨이 1 줄고(총 3개), 아슬아슬하게 피하면 니어미스 보너스를 받습니다. 튀어나오기 전에 연석에서 멈칫하는 단서가 있습니다.
- **교차로**: 80m마다 교차로가 있고, 깜빡이를 켜고 들어가면 그 자리에서 월드가 90도 돕니다. 내비 화면의 지도를 보며 목적지를 찾아갑니다.
- **하루 영업**: 정해진 시간 동안 일하고 요금에서 사고 수리비를 뺀 결과로 평점(별 0~3)을 받습니다. 번 코인으로 로비의 상점에서 업그레이드와 택시 개조를 합니다.
- 음악 리듬 없이 반응으로 피하는 방식입니다.

## 조작
| 키 | 동작 |
|---|---|
| A / D, ← / → | 조향 |
| S / ↓ | 브레이크 |
| Q / E | 좌 / 우 깜빡이 |
| Space | 손님 태우기 (로비에서는 대화 넘기기와 택시 타기) |
| X | 손님 거절 |
| Esc / P | 일시정지 (일시정지 중 U를 두 번 누르면 정산하고 로비로) |
| R | 다시 시작 |
| U | 게임 오버 화면에서 로비로 |
| O | 설정 (타이틀 / 로비 / 일시정지) |

조향, 브레이크, 깜빡이, 태우기, 거절 키는 설정의 "조작 키 설정"에서 바꿀 수 있습니다. 시작은 타이틀 화면에서 Space 또는 Enter 입니다.

## 주요 기능
- **손님 유형**: 폭탄을 든 손님, 결혼식 손님(부케), 외계인, 전직 레이서, 욱하는 손님(핸들을 잡힘, A/D 연타로 풀기), 은행 강도 등 유형마다 다른 사건이 있습니다.
- **사건과 날 종류**: 날마다 종류가 달라집니다. 평범한 날, 사람 많은 날, 괴수 침공, 히어로와 빌런 전투, 좀비의 날이 있고, 괴수/히어로/좀비는 하루 중 갑자기 시작됩니다. 정전, 라이벌 택시, 팬 습격, 돼지 떼, 구급차 같은 랜덤 인카운트도 있습니다.
- **분노 게이지**: 가득 차면 잠깐 무적이 되어 빨라지고, 다른 차를 들이받으면 폭발합니다.
- **로비**: 2D 횡스크롤 로비에서 사장, 비서, 동료 택시 기사와 대화하고 상점(업그레이드)과 택시 개조(4단계, 엔딩까지)를 이용합니다.
- **날씨와 밤**: 하루 시계, 비(앞유리 물방울과 와이퍼), 밤 조명(실제 스포트라이트).
- **영어 / 한국어**: 영어가 기본이고 설정에서 한국어로 바꿀 수 있습니다.

## 구현 포인트
- **원통형 도로**: 도로 구간을 곡선에 맞춰 배치하고 기울여서 앞쪽으로 휘어 내려가는 지평선을 만듭니다. 교차로를 도는 동안에는 휘어짐을 잠깐 줄여 먼 건물이 기울어 보이지 않게 합니다.
- **코드로 만드는 장면**: 빈 씬에 컴포넌트 하나만 붙이면 도로, 보행자, 건물, 차 내부, HUD가 전부 코드로 생성됩니다.
- **3D 팔 IK**: 어깨-팔꿈치-손목 2본 IK로 팔을 핸들에 올리고, 손가락은 핸들 접선축을 기준으로 굽혀 쥡니다.
- **도시**: Kenney City Kit(CC0)의 로우폴리 3D 건물을 세 구간(12m)마다 한 채씩 세우고(해시로 같은 길은 항상 같은 건물), 사람과 차는 2D 픽셀 아트 스프라이트 빌보드입니다.
- **밤 조명**: 차 양쪽에서 나오는 실제 스포트라이트가 앞쪽에서 모이고 도로만 비춥니다. 빛을 못 받는 2D 스프라이트는 같은 원뿔 계산으로 색을 어둡게 칠합니다.
- **구조**: 하나의 MonoBehaviour(`DriveGame`, partial class)가 뼈대이고, 보행자/택시/교차로/난이도/날씨/사건 등은 일반 C# 매니저 클래스가 이벤트로 결과를 알립니다. 튜닝 값은 모두 public 필드로 노출해서 인스펙터에서 조절합니다.
- **자동 시험 도구**: 가상 키보드로 운전하는 봇이 Unity 배치모드에서 며칠 치 영업을 돌려 오류, 사고 원인, 수입, 프레임 시간을 보고서로 남깁니다 (`Tools/run-simbot.ps1`). 화면 점검(`Tools/run-uishots.ps1`)은 글자 넘침과 번역 누락을 찾고 스크린샷을 남기며, 빌드 시험(`Tools/run-build-test.ps1`)은 개발 빌드를 만들어 분홍색 셰이더나 빠진 파일이 없는지 확인합니다.

## 성능 최적화
Unity Profiler와 Stats로 병목을 재고 고쳤습니다 (2560x1440, 에디터 측정).

| 항목 | Before | After |

| 효과음 첫 재생 최대 (소리 파일 첫 재생 때 읽던 것) | 46.8ms | 0.3ms |
| 게임 시작 직후 첫 렉 프레임 | 680ms | 26.5ms |
| 로비 Tris | 146.2k | 1.6k |

- 소리 데이터를 로딩 화면에서 미리 메모리에 올려 첫 재생 때의 파일 읽기를 없앴습니다 (로딩 화면은 약 2.5초).
- 로비에서는 보이지 않는 3D 월드를 그리지 않고, 길가 소품 재질은 공유합니다.

## 실행 방법
1. Unity 6 (6000.3.5f2)로 프로젝트를 엽니다. URP, 새 Input System을 사용합니다.
2. 아래 **에셋** 항목의 파일을 `Assets/_External/`에 넣습니다. (없어도 도형과 코드로 만든 소리로 대체되어 실행은 됩니다)
3. 픽셀 아트 팩을 넣었다면 `python Tools/build-pixel-atlas.py`로 한 장의 아틀라스를 만듭니다.
4. `Assets/Game/Scenes/DriveScene.unity`를 열고 Play를 누릅니다.

씬을 새로 만들려면 메뉴 `Game → Create Drive Scene`을 사용합니다.
